树洞

故事的开始，是一个来自江浙沪的天才小登。高中三年，他左手 CMO/IMO，右手 NOIP/NOI/IOI，偶尔参加 ACM/ICPC/CCPC，闲暇之余甚至还想试试 CPHO/IPHO。作为一个手握竞赛金牌、进入国家集训队（国集）的顶级竞赛生，他原本可以去隔壁的姚班、智班、图班、通班，也可以通过数学英才班、人才计划直通 yau 的求真书院，但最终还是被北京大学「思想自由，兼容并包」的精神感召，选择保送 PKU 的 sms（数院），立志将毕生奉献给基础数学。彼时他对 xk（信科）、wy（物院）、yp（元培）、gsm（光华）的同学不屑一顾，认为计算机、统计学、金融数学、应用数学、计算数学不过是数学的低级应用，至于 cs、ai、at、quant 更是亵渎学术的异端。他的终极理想，是在三十岁前解决黎曼猜想、挂谷猜想、雅可比猜想和 NS 方程，拿下菲尔兹奖、考普斯奖、考普斯会长奖、未来科学大奖，让 yau 亲自为他颁奖。

大一那年，他每天在二教刷着绩点，轻松拿下国奖，一边跟数学英才班的同学讨论解析数论，一边嘲笑对着 LeetCode 刷题的信班小登没有 sense。直到大二，他终于意识到一个残酷的事实：基础数学是真的 discouraged，而且这个领域似乎不遵循 Scaling Law。自己苦思三个月的引理，隔壁 AI 小登让 GPT 想了三分钟就编出来了，虽然是错的，但至少人家有输出。更可怕的是，朋友圈里当年 NOI 不如自己的同学，已经在字节跳动、腾讯、智谱拿了实习 offer，甚至开始讨论大包。他第一次怀疑，自己是不是应该把才华埋葬在昨天。某天凌晨三点，他在树洞发帖：「求问，sms 大二转 AI 还来得及吗？是转专业、降转、跨保，还是直接申请美硕？软微、深研院、通研院、智能学院、AI 院、中关村学院哪个更有前途？保研、直博、专硕、金融硕、选调、秋招、校招到底哪个是最优解？有没有懂哥交流一下？」底下第一条回复：「本质是你认知不够，建议 gap 一年。」第二条回复：「区。」

痛定思痛，他决定拥抱人工智能的黄金时代。凭借竞赛生的底子和几篇速读的 machine learning / deep learning 论文，他迅速用 ML、DL、CV、NLP、LLM 武装了自己的简历，声称自己对大语言模型有着深刻理解。为了进组，他在叉院、智源和各大强组之间反复横跳，最终决定投身基模。起初他研究 infra，觉得算法都是调参；后来研究 post-train，觉得 infra 都是搬砖；再后来搞 RL、RSI、agent、harness、benchmark、RAG、蒸馏，觉得大家都没有触及 AGI 的本质。等到 VLA、embodied、具身、world model 火起来，他又突然顿悟：「语言终究不是智能的全部，物理世界才是真正的 deep。」但过了一个星期，他发现 AI4Math、AI4S、AI4Science 似乎更有 sense，于是重拾当年的数学梦想，决定让 AI 替自己证明黎曼猜想。

那段时间，他每天高强度研究大模型格局：国内关注深度求索（DeepSeek / ds / dpsk）、智谱（GLM）、月之暗面（Moonshot / Kimi）、MiniMax、阶跃星辰（StepFun）、千问（Qwen）、腾讯混元（Hunyuan）、豆包（Seed）、MiMo、LongCat、Fable，海外则密切跟踪 OpenAI（OAI）、Anthropic（a/）、Google（谷歌） 的进展。上午用 Codex 写代码，下午看 Claude Opus，晚上测试 Gemini、Grok、GPT，睡前还要研究一下 Astra、a\ code、Muse 的新动态。每当某家发布新模型，他都第一时间锐评：「基模的核心是 Scaling，国内除了 DeepSeek 都是炒作，其他人做的不过是蒸馏。」等第二天发现新模型 benchmark 反超了，他便若无其事地修改观点：「本质是 post-train，pre-train 已经没有壁垒了。」第三天又改口：「其实 AGI 的终局一定是 agent + embodied。」一时间，树洞里的基模哥、基模弟、基小弟、智源哥纷纷奉其为懂哥。

然而，真正改变他命运的，是一位从光华转来搞量化的室友。某天室友轻描淡写地提了一句：「我在 Jane Street 面完了，感觉还行。」他当场破防。原来自己辛辛苦苦读论文、调模型、刷 benchmark，竟然还不如对面学统计的同学做 QR/QT/QD 来钱快。当天晚上，他立刻开始研究 Quant，把签名从「Towards AGI」改成了「Seeking Alpha」。他发现国内内资机构里，幻方（hf）、九坤（jk）、衍复（yf）、宽德（kd）、明汯（mh） 个个卧虎藏龙，此外还有世纪前沿（sjqy）、顽岩（wgby）、思勰（sx）、灵均（lj）、平方和、天演、乾象、因诺、鸣石、蒙玺、量派、黑翼、聚宽、正定、半鞍、安贤、微观博易、邦戴数科（bd）、世坤（scientech） 等一众神秘势力。他一边在树洞研究哪家是头部、颈部、臀部，一边询问 佳期 有没有 conn，并逐渐形成了一套完整的量化方法论：「本质是国内卷 alpha 没有意义，有 sense 的人都应该去外资自营。」

于是他开始冲击 Prop Shop。从 Jane Street（JS）、HRT、Citadel、Jump、Optiver 到 IMC、Tower、DRW、SIG、Virtu、Akuna，从 Two Sigma（2sigma）、Point72、Cubist、D. E. Shaw、Millennium 到 QRT、ScientEch，他把所有公司都研究了一遍，每天不是在做概率题，就是在跟颈部哥讨论行情。为了证明自己具备真正的 Quant sense，他还专门写了一个基于 Transformer 的策略，号称可以用 RL 从市场中自动挖掘 Alpha。结果回测收益很好，实盘第一天就爆了。他大受震撼，遂发表最新认知：「本质是金融市场非平稳，传统 ML 和 DL 都不行，真正的 Alpha 要靠数学直觉。」但还没等他重新研究概率论，就听说有人在 Crypto 赚了大钱，于是又开始研究链上交易，准备跟孙哥（孙割）混。三天后，他的全部加密资产只剩下一个钥匙扣，以及一条「感谢参与」的空投记录。

到了大三，他已经完成了从基础科学到互联网大厂、从大模型到量化、从内资到外资、从人工智能到 Crypto 的完整思想进化。他的简历上同时写着「AI4Math、LLM Agent、Quantitative Research、Alpha Mining、VLA、World Model」，职业规划则是「优先头部，保底颈部，拒绝臀部」。他经常在树洞跟眼王（👁️王）、ph帝、ph弟、通京男、通登、ztf 等神秘人物激情对线，今天说 AI infra 才是未来，明天说 QR 才是正统，后天又说现在最大的机会是创业。每次看到有小登问「北大究竟是读博好还是就业好」，他都会发出意味深长的回复：「看个人认知。真正的 T0 早就不纠结这些了。」如果有人追问他的实际经历，他就会说：「不方便透露，之前在某头部做过一段时间，圈子太小，怕被定位。可以 vx，交流一下，vx1。」

大四那年，故事终于迎来了转机。为了躲避秋招，他决定创业，拉上一个姚班的 OI 金牌、一个智班的 ICPC 选手、一个物院的理论物理天才，还有一位从光华来的金融数学小登，成立了一家名为「Deep Alpha Intelligence」的初创公司。公司的愿景，是通过 AI4Science + Quant + Embodied Agent 实现通用人工智能，顺便重构全球金融市场。他们给投资人讲 Scaling Law、RSI、AGI、world model，给科研基金讲基础科学、数学、黎曼猜想，给量化机构讲 Alpha、策略、QR、QD，给大厂讲基模、infra、post-train，给政府讲人工智能、产业升级、人才培养。投资人听完纷纷表示：「方向非常 deep，团队很有 sense，但你们到底做什么？」他微微一笑：「我们做的是下一代通用智能基础设施，本质是重构生产关系。」

项目最终由于没有商业模式而被迫停止，他也错过了校招。看着室友已经拿着 Citadel 的大包准备毕业，自己却还在纠结申请、保研、直博、跨保，他终于意识到：当年那个想证明黎曼猜想的少年，似乎真的已经把才华埋葬在昨天。于是，在一个寂静的深夜，他重新回到二教，打开四年前的数学笔记。第一页上赫然写着：「数学的美，不在于它能带来什么，而在于它揭示了世界最深刻的真理。」他久久凝视着这行字，眼眶微微湿润，仿佛又看到了那个曾经相信基础科学能够改变世界的自己。

他沉默了很久，终于重新打开电脑，在树洞发了一条帖子：

「求问各位大佬，sms 本科 + AI/Quant 交叉背景，之前有创业经历，现在回归基础数学冲菲奖还有机会吗？感觉 AI4Math 可能是未来十年的黄金时代，想找个强组读博做 AGI for Math。国内国外都考虑，最好能兼顾一点 Infra 和 Quant，不太想纯做理论。有没有 OAI、a/、DeepSeek、Jane Street 的大佬给个内推？本人竞赛金牌，国集出身，认知在线，有 sense，不是区。欢迎交流一下，已 vx1。」

三分钟后，评论区出现了一个熟悉的头像。

👁️王：「本质是你还没有找到自己的热爱。」

ph帝：「典。」

通京男：「不如上嫁。」

颈部哥：「你这背景来我们这里最多算臀部。」

基模哥：「不如先跑个 benchmark。」

匿名用户：「哥们你到底想干什么？」

他想了想，认真地回复：

「想拿个大包。」

这可能就是传说中的 PKU 终极形态：认知已 T0，人生仍在 benchmark。
